# Bank Loan Analysis Dashboard

## Project Overview
This project analyzes bank loan applications, loan status, credit scores, customer income, and loan purposes using Python, MySQL, and Power BI.

## Objectives
- Analyze total loan applications.
- Compare fully paid and charged-off loans.
- Analyze loan amounts by purpose, term, and employment length.
- Explore credit scores, annual income, and customer credit balances.
- Build an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Tools Used
- Python — Data analysis and visualization
- MySQL — Data querying and analysis
- Power BI — Interactive dashboard
- GitHub — Project documentation and version control

## Dashboard Highlights
- Total Loan Applications
- Total Loan Amount
- Good vs Bad Loan Applications
- Loan Amount by Purpose
- Loan Amount by Term
- Loan Amount by Employment Length

## Dataset
Dataset: [Credit Risk Dataset on Kaggle](https://www.kaggle.com/datasets/zaurbegiev/my-dataset)

## Project Structure
- `Python/` — Python analysis script
- `SQL/` — SQL queries
- `PowerBI/` — Power BI dashboard
